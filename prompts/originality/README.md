# Copyright originality prompt (out of current product scope)

`originality.py` holds a draft prompt for copyright originality assessment
(独创性：独立完成 + 最低限度创造性、思想/表达二分法、混同与有限表达过滤、
接触 + 实质性相似证据缺口).

It is deliberately **not** part of the patentability assessment boundary: the
product specification (6.6) covers novelty, inventive-step combination risk,
and evidence completeness only, and 独创性 is a copyright-law concept. This
prompt stays here as a reviewed draft until a copyright-evidence case type is
confirmed. Do not import it from `prompts/assessment`.
